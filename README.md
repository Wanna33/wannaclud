# WannaClud Cócteles

Sitio web estático (HTML, CSS y JavaScript). No necesita instalación.

- `index.html`: la página completa.
- `img/`: fotos de las latas y logo.

Para cambiar el número de WhatsApp, los precios o los sabores, abre `index.html`
y busca el bloque `CONFIGURA AQUÍ` al inicio del script.
